# Somfy IO Shutter Manager

Local, independent Home Assistant control for Somfy io-homecontrol 1W shutters
through an ESP32 and CC1101 bridge.

Each shutter gets its own cover, native MY button, and friendly physical-remote
diagnostic. The graphical workflow supports pairing, importing existing
controller identities, travel-time calibration, encrypted recovery, and safe
slot moves or swaps across up to 20 shutters per bridge.

The compatible ESPHome manager firmware must be installed before adding the
integration. Follow the full hardware, firmware, safety, and commissioning
instructions in the repository README.
